# 办公 Wi-Fi 与访客网络隔离（演示手册）

以下为虚构企业 IT 支持演示规范，不代表真实公司的接入参数、审批时效或授权。

## 适用与判别

适用于员工能上网但连不到公司内网、或不确定连接了哪类 Wi-Fi 的场景。访客网络和办公网络可能有不同访问策略，本演示资料不提供真实 SSID、密码或接入证书。先确认员工设备、网络类型及目标系统，而不是猜测公司 Wi-Fi 名称或公开询问密码。

## 处理步骤

办公 Wi-Fi 处理：核对设备连接的是企业要求的办公网络还是访客网络；访客网络能访问公网不代表可以访问内部系统。需要办公接入资格时按企业流程由 IT 核验，不靠改 DNS 或代理绕过隔离。已有资格但连接失败时记录连接提示、位置及其他设备是否受影响，再交网络支持。

## 验证与交接

Wi-Fi 验证：分别记录公网和已授权内网服务的访问结果。在允许范围内重新连接并观察提示，不执行未批准的网络重置。网络名称及凭据由企业正式渠道确认，不在聊天中发送密码或私钥。多人同区域异常应说明地点范围和发生时间，不声称已确认无线控制器故障。
