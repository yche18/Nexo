# macOS 软件来源校验与安装限制（演示手册）

以下为虚构企业 IT 支持演示规范，不代表真实公司的接入参数、审批时效或授权。

## 适用与判别

适用于 macOS 安装应用时提示来源无法验证、应用受管理策略限制等情形。这些提示不等于 Windows 1603，也不能直接认为安装包损坏。先记录应用名称与版本、系统版本、获取来源及准确提示，明确是否是企业设备和是否来自批准的软件分发渠道。

## 处理步骤

macOS 安装处理：使用企业批准的软件目录或经 IT 确认的官方安装包；出现来源或签名警告时先停止打开并请 IT 核验发布来源与设备策略。不要关闭系统安全校验、绕过企业管理、执行来源不明的终端命令或强行移除隔离标记。更新现有应用前保存工作，涉及覆盖数据或配置时先确认备份。

## 验证与交接

macOS 安装验证：在 IT 确认适用版本和批准操作后观察同一应用能否正常打开，未实际操作不能记录为安装完成。交接包括来源、版本、提示摘要和批准渠道信息，避免上传私钥或敏感安装日志。许可证与管理员资格仍须企业核验，不由助手推断或开通。
