# 代理 407：代理认证边界（演示手册）

以下为虚构企业 IT 支持演示规范，不代表真实公司的接入参数、审批时效或授权。

## 适用与判别

适用于访问网页时明确出现 407 Proxy Authentication Required。407 指向代理认证，与目标应用的 401 或 403 不同；仍需核对错误页面是否来自企业代理。记录系统、浏览器、目标站点类别及网络环境，不把所有登录提示都归为项目系统权限不足。

## 处理步骤

代理 407 处理：核对是否使用企业批准的网络和代理配置，并通过企业正式登录方式完成代理认证；无法确认入口或反复弹窗时交给 IT 核验账号与代理策略。不要让用户在陌生弹窗输入凭据，不修改成开放代理、删除企业代理配置或用关闭安全软件来绕过认证。

## 验证与交接

代理 407 验证：记录仅一个浏览器还是多个应用受影响，以及完成批准登录后的实际结果。目标系统仍返回 401 时应继续检查应用认证，不能认为代理登录同时授予业务权限。交接包含错误码、时间、网络类型和已尝试步骤，不包含代理密码或认证头。
