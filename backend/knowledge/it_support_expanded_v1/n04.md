# 内网 DNS：域名解析与访问条件（演示手册）

以下为虚构企业 IT 支持演示规范，不代表真实公司的接入参数、审批时效或授权。

## 适用与判别

适用于内网域名解析失败、找不到服务器等现象。先记目标域名的可公开部分、原始错误、发生时间、设备网络和影响范围，避免粘贴带密钥的完整 URL。区分普通公网也不可用、只有企业域名不可用、以及域名可解析但应用返回错误；这些现象不应直接当成同一种故障。

## 处理步骤

内网 DNS 处理：确认普通网络访问，再确认该资源是否要求企业网络或 VPN。如果未接入要求的网络，先按批准方式建立连接；若已经连接，按企业指引请 IT 核对 DNS 配置及解析结果，不自行替换成公共 DNS。仍未取得资源权限时按权限流程处理，DNS 改动不能替代授权。

## 验证与交接

内网 DNS 验证：保留连接企业网络前后的错误差异及同事是否也受影响。只有某一域名失败时不重置整机网络；多个用户同时间失败时整理共同时间线交给网络支持。助手没有实时 DNS 探测能力，不能说已验证解析记录、已清理缓存或已修改服务器。
