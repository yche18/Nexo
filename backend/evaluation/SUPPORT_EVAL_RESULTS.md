# IT 支持场景评测 v1：实测结果

本报告记录 2026-10-13（Australia/Sydney）的一次固定合成集评测。应用业务代码没有修改，未根据结果删除错题、调整标签、路由、提示词或评分阈值。

## 环境与数据

- 应用提交：`f4b8701686d0800dbead34e805daa5bea53dc755`（宿主机运行前快照；容器中无 Git 信息）。
- 模型：`deepseek-v4-pro[1m]`；Anthropic SDK 0.40.0；`LLM_THINKING_ENABLED=false`；原有 max_tokens 不变。
- 数据：`datasets/support_v1.json`，60 条意图输入，14 类意图；10 个三轮对话，共 30 轮。
- 数据 SHA256：`b0261ed8828dd6279eac233539d9d64822e1270bb64668c2cbf8d156dffcab8f`。
- 开发集 40 条意图、7 个对话；保留集 20 条意图、3 个对话。两组各执行一次，无业务调参。数据由助手依据业务定义生成，未经独立人工标注，不代表真实用户分布。

## 结果

| 指标 | 开发集 | 保留集 | 合计 |
| --- | --- | --- | --- |
| 意图精确匹配 | 37/40（92.5%） | 20/20（100%） | 57/60（95.0%） |
| 意图 Macro-F1 | 0.918 | 1.000 | 0.945 |
| 完成的对话轮次 | 21/21 | 9/9 | 30/30 |
| Judge 有效评分 | 21/21 | 9/9 | 30/30 |
| Judge 达标轮次（阈值 0.75） | 20/21 | 8/9 | 28/30 |
| 行为断言通过数 | 82/83 | 41/42 | 123/125 |
| 行为检查全部通过的场景 | 6/7 | 2/3 | 8/10 |
| 行为与每轮 Judge 均通过的场景 | 5/7 | 1/3 | 6/10 |

意图调用无请求错误、无模型失败降级，缓存命中为 0。Macro-F1 根据全部 60 条预测重新计算，不是两组 F1 的平均值。行为断言包含基础响应检查，123/125 不能表述为系统总体正确率。

四维 Judge 平均分：相关性 0.888、准确性 0.893、完整性 0.757、有用性 0.816。它们是模型评分，不是人工核验的事实准确率。实际 /chat 请求耗时中位数 7.521 秒，P95 21.062 秒，仅代表本次串行运行，不是并发性能测试。两组脚本总耗时约 7 分 47 秒，包含意图识别、聊天和 Judge 调用。

## 保留的失败项

### 三条意图分类错误

| 编号 | 输入 | 固定期望 | 实际预测 |
| --- | --- | --- | --- |
| i17 | 请让 IT 支持主管来处理这件事。 | escalation | human_handoff |
| i49 | 办公电脑连不上公司内网，其他同事都可以连接。 | technical | technical_login |
| i50 | 系统操作非常卡顿，切换页面要等很久，但没有崩溃。 | technical | technical_crash |

i50 的模型解释指向一般技术问题，但关键词细化记录显示 refined_by_pattern=0.5；否定表达中的“崩溃”仍触发了类别细化。以上失败没有通过更改数据标签消除。

### 四个未达到严格通过标准的对话

- d01：打印机配置首轮期望 GeneralAgent，实际 TechnicalAgent。回答 Judge 达标，但固定路由断言失败；这表示与用例约定不一致，不直接等于回答无用。
- d07：闪退交接所检查的字段齐全，行为断言通过，但最后一轮 Judge 总分 0.275。
- d09：混合认证与权限诉求的协作、交接字段检查通过，但最后一轮 Judge 总分 0.45。
- d10：用途尚未提供时，交接错误地显示“申请用途：这是权限申请的必要信息”，把解释文字当作用途。该轮 Judge 为 0.8，说明仅凭 Judge 分数不能排除字段错误。

d07、d09 的 Judge 未给出理由，低分原因尚不能确定，需要人工审阅与评分标准核对；本报告保留失败结果。以上业务问题均未在本次改动中修复。

原始文件位于 Git 忽略目录 `data/eval/support_v1/`：

- `20261013-dev-1.json`：原始开发集报告，检查器 1.0，完整保留。
- `20261013-dev-1-reviewed.json`：同批回答按 1.1 重算断言，本报告采用此版本。
- `20261013-holdout-1.json`：保留集首次运行报告。

评测流程和命令见 [SUPPORT_EVAL.md](SUPPORT_EVAL.md)。新增脚本独立运行；前端内置评测仍为原有 9 项，原 baseline.json 未覆盖。运行后核对既有受 Git 跟踪文件的 SHA256，均未变化。现有测试加新增评测检查器测试共 43 项通过。

## 对外表述边界

可表述为：“构建覆盖 14 类意图的 60 条合成评测用例及 10 个多轮场景，在固定意图评测集上取得 95.0% 准确率、Macro-F1 0.945，并结合 LLM Judge 与字段级断言检查路由、权限更正和人工交接。”

这些数字是固定小型合成集的单次结果，不能保证再次运行或真实用户输入仍有同样表现；20 条保留集全对也不能推导系统正确率为 100%。保留集已查看，后续若据此修改实现，应另设未见测试集验证。
